    Before you clone it

    What runs today?
    Document loaders, chunking, embeddings, semantic and keyword retrieval, fusion and reranking.
    What is not built yet?
    The agents, corrective grading, generation, multimodal search, memory and evaluation.
    What does it need?
    Python 3.11 or later. Docker Compose starts Qdrant and Redis.

    Run it on your machine

    FastAPI serves its own docs at localhost:8000/docs.
